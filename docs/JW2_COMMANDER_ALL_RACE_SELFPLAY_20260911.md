# 네 종족 사냥 가능성 점검과 PPO 자기대전 (2026-09-11)

사용자는 엘프 외 종족도 사냥을 학습할 수 있는지 확인하고, 가능한 경우 PPO
대전 학습을 진행하도록 지시했다. 네 종족 모두를 대상으로 별도 실험을 시작했다.
기존 최상 모델은 보존하며, 이 파일의 아래 결과는 실험 완료 후 기록한다.

실험 디렉터리: `debug_artifacts/commander/all_race_selfplay_20260911`.
원시인 0, 엘프 1, 티라노 2, 데몬 3을 경기마다 명시한다.
실행 파일은 기존 `build/demon_foundation_v1_20260910/ranker_rebuild.exe`이며,
배포 파일이나 게임 규칙을 수정하지 않는다.

## 사냥 가능성 점검

| 종족 | 점검한 모델과 자료 | 사냥 준비 |
|---|---|---|
| 원시인 | v101의 개발 48경기, 사냥 0회. 합법 접두사 5,184개에서 HUNT 평균 확률 약 1.18e-7 | 실험용 복사본에서 사냥 탐색 초기화 |
| 엘프 | v108은 앞선 실제 평가 12경기 모두 사냥 실행. 이번에는 v103 개발 관측에서도 확률을 재계산 | v108을 실험 출발점으로 사용; 채택 모델은 v103 유지 |
| 티라노 | v20의 남아 있는 결정적 개발 24경기에서 사냥 23회. 해당 관측을 v23으로 재계산한 HUNT 최대 확률 약 0.949 | v23의 기존 사냥 출력 보존 |
| 데몬 | v102의 개발 48경기, 사냥 0회. 합법 접두사 8,149개에서 HUNT 평균 확률 약 1.49e-9 | 실험용 복사본에서 사냥 탐색 초기화 |

티라노 v23 직전 학습의 원본 RLO는 보존되어 있지 않아 그 자료로 확률을
검사하지 않았다. 대신 남아 있는 v20 관측을 **읽기 전용으로 v23에서 재계산**했다.
과거 행동 수와 현재 모델의 확률을 구분한다. 실제 v23의 사냥 실행 여부는
이후 새 native 자기대전에서 별도로 확인한다. 이 과거 점검 자료는 PPO에 넣지 않는다.

원시인·데몬의 현행 foundation 교사에는 HUNT 분기가 없다. 두 모델에 대해서만
HOLD의 전체 조건부 출력 행을 HUNT에 복사하고 logit을 4 낮춰 탐색을 준비했다.
HOLD가 합법일 때 HUNT 확률은 이 초기화로 약 1.8%를 넘지 않는다. 다른 출력의
원시 logit과 경제·특징·critic 파라미터는 그대로이며, 실제 실행 시의 조건부
마스크를 유지한다. 이것은 승률 개선이나 사냥 시점 학습 완료가 아니다.
이 초기화 **후에 새로 수집한** 행동·확률로만 PPO를 진행한다.

사냥의 실제 실행은 각 소유자 리플레이의 subtype 0x0b 사냥 표식과 subtype
0x02 대상 지정 acquire 명령으로 확인한다. 패킷 수를 중립 처치 수나 경험치
획득량으로 보고하지 않는다. 중립 처치에 대한 경험치 지급 경로는
`ranker_unit_damage.cpp`와 `ranker_winmain.cpp`에서 확인했다.
현재 보상에는 사냥 명령 자체에 대한 추가 보상을 넣지 않는다.

## 수집과 PPO 계획

각 수집 라운드는 다음 **40경기**다.

- 현재 고정 모델끼리 16경기: 네 종족의 모든 조합. 양쪽의 현재 모델 경험을 사용.
- 과거 고정 모델 상대 16경기: 학습 중인 1번 진영의 경험만 사용.
- 내장 AI 상대 8경기: 종족별 2경기.

총 신경망 대전 비율은 80%다. 종족별로 1번 진영 10개와 2번 진영 4개의
trajectory, 즉 **14개 경기 관측**이 학습에 들어간다. 네 종족의 관측 수를 합한
56개는 물리적으로 서로 다른 56경기라는 뜻이 아니다. 이 중 같은 경기의 양쪽
기록이 포함돼 있다. 상대 모델의 레이스·해시·버전이 현재 모델과 정확히 일치하는
경우에만 2번 진영의 경험을 학습에 넣는다.

1. `collect0`: 초기화된 정책들로 첫 40경기 수집.
2. `warm`: 해당 경험의 Monte Carlo return으로 종족별 critic만 6 epoch 보정.
   actor와 보호된 출력이 정확히 같은지 확인한다.
3. `collect1`: critic이 보정된 모델로 **새 40경기** 수집.
4. `fit`: 각 종족에 PPO 3 epoch, lr 1e-5, gamma 1, GAE lambda 0.98.
   경제 출력·공유 특징·접두사 임베딩은 고정하고 전투 출력과 critic을 갱신한다.
   초기 탐색 모델에 대한 KL 계수 0.05를 사용한다.
5. `screen`: 종족별 고정 개발 12경기 평가. 티라노는 현재 실행 파일에서 v23과
   동작이 같은 초기 복사본의 12경기 대조도 새로 실행한다. 나머지 종족은 같은
   실행 파일에서 평가된 기존 최상 모델의 동일 조건 기록과 비교한다.

이 파일럿에서는 챔피언을 교체하지 않는다. 작은 선별 평가만으로 기존 48경기
성적을 뛰어넘었다고 주장하지 않는다. 자기대전 승률도 대진 구성이 바뀌면 단순
전후 비교할 수 없으므로, 내장 AI 상대 고정 평가와 사냥 상황 지표를 함께 본다.

## 자료와 실행 검증

`ranker_commander_selfplay_batch.py`에 종족을 명시하는 대진 생성과 현재 모델
소유자만 학습에 포함시키는 검사를 추가했다. 관련 테스트 5개가 통과했다.
다른 종족·다른 모델·다른 버전의 자료, 평가/교사 자료, 중복 경로, 두 소유자의
모순된 종료 상태를 거부한다.

native 경기에서도 양쪽 시작 종족, 관측의 자기 종족·상대 종족, 모델 버전,
종료 프레임·승패의 일치와 액션 마스크를 확인한다. PPO 직전에는 모든 학습
행동의 log probability와 value를 해당 가중치로 재계산한다. 새 정책의 KL은
0.05 이하, clip fraction은 0.20 이하일 때만 다음 평가에 진입한다.
모델·실행 파일·코드·수집 자료의 해시와 평가 결과를 별도 manifest에 고정한다.

진행 상태는 기존 `training_run/state.json`, 각 완료 코호트의 채팅 보고 확인은
`training_run/chat_reports.jsonl`에 남긴다. 완료 결과는 먼저 채팅으로 보고하고
그다음 ACK한다. Windows 알림은 사용하지 않는다.

## 완료 결과

코호트 249~253 완료. 학습 대전 80경기(신경망 대전 64, 내장 AI 16),
critic 보정 68,540개 행동과 별도 새 PPO 수집 72,660개 행동을 사용했다.
네 종족 모두 critic 보정 1회와 actor PPO 3 epoch 갱신 1회를 완료했다.
critic 보정에서는 actor가 정확히 같았고, PPO에서는 전투 출력이 실제 변경되었으며
보호한 경제 출력과 공유 특징은 정확히 유지되었다. 수집/평가 액션 마스크 위반은 0이다.

| 종족 | PPO 개발 평가 | 비교 모델 승수 | 평가 중 HUNT 명령 |
|---|---:|---:|---:|
| 원시인 | 10승 1패 1시간초과 / 12 | 11 / 12 | 0 |
| 엘프 | 9승 3패 / 12 | 11 / 12 | 915 |
| 티라노 | 11승 1패 / 12 | 12 / 12 | 2 |
| 데몬 | 11승 1패 / 12 | 12 / 12 | 0 |

모든 종족이 확률적 학습 수집에서 실제 사냥을 실행했지만, 원시인·데몬의
최대 확률 행동 평가에서는 HUNT를 선택하지 않았다. 사냥 가능성과 사냥 전략의
성공을 구분해야 한다. 이번 후보는 최상 모델로 채택하지 않았다.
티라노 비교는 동일 실행기에서 v23의 정확한 복사본으로 새로 실행한 12경기다.
엘프의 자기대전 출발점 v108은 선택 모델 v103과 다른 실험 후보이므로,
9/12 대 11/12 차이를 이번 PPO 갱신만의 인과 효과로 해석할 수 없다.

최종 데이터·가중치 검증은 실험 디렉터리의 `completion.json` 및
`final_verification.json`에 기록했다. 기존 최상 모델은 유지한다.
이 절은 검증 완료 직후 보완했으며 문서 변경 이력은 `document_closeout.json`에 남긴다.

사용자가 네 종족의 공격 중 반복 후진을 지적하여 다음 실험은
`debug_artifacts/commander/march_cohesion_20260911`에서 공통 이동 실행기를 수정하고
동일 가중치 전후 비교 후 새 환경의 on-policy 경험으로 학습을 계속한다.
