  행동의 간접적인 변화까지 같다고 주장하지 않는다.

## 반복 절차

1. 최신 실행기에서 출발 모델을 각 48경기, 총 192경기 평가한다.
   각 종족이 상대 4종족 및 측정된 12개 순서 있는 시작 배치를 모두 만난다.
2. 80경기를 확률적으로 수집하여 critic을 6 epoch 보정한다.
   actor 파라미터가 정확히 보존되는지 확인한다.
3. 별도의 새 80경기를 수집하고 PPO를 3 epoch 실행한다.
   minibatch 1024, gamma 1, GAE lambda 0.98, 출발 모델 KL 계수 0.05.
4. 갱신 후 전체 코호트 KL ≤ 0.02 및 clip fraction ≤ 0.15를 확인한다.
   실패한 종족의 후보는 평가/후속 학습에 채택하지 않는다.
5. 같은 192개 조건에서 평가한다. 종족별 48경기 승수가 증가했을 때만
   이 실험의 최상 모델을 변경한다. 동률과 3경기 이내의 변동에서는 학습
   후보를 계속 발전시킬 수 있지만 최상 모델은 보존한다. 4경기 이상
   떨어지면 다음 수집의 해당 종족을 최상 모델로 되돌린다.
6. 연속 3회 모든 종족의 최상 승수가 정체되면 `analysis_required`로
   전환한다. 이는 전체 목표의 완료나 중단 선언이 아니다. 실패 경기와
   행동·관측·보상·학습기·native 실행기를 점검한 후 다음 조정을 정한다.

각 80경기는 현재 정책 상대 32경기, 보존 정책 상대 32경기, 내장 AI
16경기로 구성된다. 종족 배정·대진 순서·배치는 재현 가능한 난수로 섞고
현재/보존 정책 블록에서 모든 종족 조합을 보장한다. 상대 소유자의 자료는
그 종족의 현재 체크포인트 해시와 버전이 정확히 일치할 때만 사용한다.
현재 모델과 보존 모델이 같으면 두 블록 모두 양쪽 경험을 사용할 수 있다.
같은 경기의 두 시점을 별개의 물리적 경기로 세지 않는다.

## 신뢰성과 진단

실행기·소스·출발 가중치 해시를 고정한다. 완료 경기마다 종족, 소유자,
모델 버전, 종료 결과, 합법 행동 마스크를 확인하고, 모든 결정의 native
log probability와 value를 Python에서 재계산한다. 오차 0.005 초과를 거부한다.
행동 빈도, HUNT 횟수, 명령 거절 수와 원본 RLO·리플레이·로그를 보존한다.
결정적 평가, 교사 정답 또는 다른 정책의 자료를 PPO 경험으로 사용하지 않는다.

재시작은 OS 파일 잠금으로 중복 실행을 막고 완료한 단계의 체크포인트와
정확한 경기 조건을 확인한다. 완료 영수증이 없는 기존 게임 디렉터리는
자동 재실행하지 않는다. 먼저 해당 프로세스의 상태를 조사해야 한다.

이번 실행기의 관련 테스트 13개가 통과했다. 대진/선택/영수증 검사 외에
네 종족의 critic 보정 → 새 확률값의 PPO → 가중치 내보내기·재개를
합성 자료로 실제 실행해 actor 보존과 학습 경로를 확인했다.
실제 학습 성과는 아직 검증 전이며, 실행 중인 기준 평가의 일부 승패를
네 종족 전체 승률이나 새 PPO의 성과로 보고하지 않는다.

재개 명령(기존 컨트롤러가 종료됐다는 것을 확인한 뒤):

```powershell
.\.venv-ai\Scripts\python.exe -u -B ranker_reconstructed_code/tools/ai/ranker_commander_improve.py debug_artifacts/commander/ppo_improvement_20260911
```

이 실험은 배포 실행 파일이나 기존 챔피언 레코드를 교체하지 않는다.

## 독립 평가 준비와 기준 평가 중 발견한 문제

`ranker_commander_holdout.py`를 추가했다. 기존 학습/개발 시드와 겹치지 않는
1819000000번대의 시드를 고정하고 native 실행 23회로 모든 12개 시작 배치를
확인했다. 각 실행은 64프레임의 배치 탐색이며 승률 평가나 PPO 학습 자료가
아니다. 배치별 첫 관측 시드만 선택해 승패에 따른 시드 선택을 피했다.
자료는 `debug_artifacts/commander/ppo_improvement_20260911_holdout/`에 있다.

선택된 네 모델을 고정한 후 각 종족마다 상대 4종족 × 배치 12개를
최대확률 행동과 확률적 행동으로 평가한다. 총 384경기다. 시드 중복,
모델 변경, 누락 경기, 마스크 위반, 시간 제한에 의한 거짓 전승을 거부하는
관련 테스트 6개가 통과했다. 이 독립 평가의 실제 승패 측정은 아직 전이다.

```powershell
.\.venv-ai\Scripts\python.exe -u -B ranker_reconstructed_code/tools/ai/ranker_commander_holdout.py evaluate --campaign debug_artifacts/commander/ppo_improvement_20260911 --directory debug_artifacts/commander/ppo_improvement_20260911_holdout --roster <검증할_네_종족_선택파일.json>
```

기준 평가를 계속 실행하면서 이미 완료된 비승리 경기의 원본 자료를
`inspect_failures.py`로 읽었다. 이 자료를 PPO에 넣거나 행동을 재라벨링하지 않는다.

- 원시인/데몬의 패배 3경기에서 본진 근처에 적이 관측되고 주력이
  본진에서 896px 이상 떨어진 시간의 추정치는 976/1440/1888프레임이었다.
  같은 모델·상대 종족의 다른 시작 배치 승리 경기에서는 0이었다.
  서로 다른 시드·배치이므로 인과 효과를 증명한 대조 실험은 아니다.
- 목표 변경은 승리 경기에서도 잦았다. 프레임당 변경 횟수가 승패와
  일관되게 대응하지 않아 단순 변경 벌점부터 추가할 근거는 부족하다.
  실행기의 긴급 DEFEND 개입과 실제 정책 출력의 변경을 별도로 계산했다.
- 엘프 대 티라노, seed 17 / 시작 [0,2]는 60000프레임 시간 제한이었다.
  30000프레임 이후 적 건물을 기억하는 721개 결정에서 MAIN 명령이
  합법이었지만 모두 NONE을 선택했다. 이 구간은 기존 ATTACK_MOVE,
  탐색 anchor 12를 유지했다. 해당 조건의 NONE 확률은 평균 0.98339였고
  종료 시 상대 건물 34개가 남았다. 마스크 위반과 명령 거절은 0이었다.
  적 건물 정보가 관측에 들어 있으며 실행 가능한 명령을 정책이 선택하지
  않은 사례다. 새 확률적 PPO에서 마무리 공격 경험이 늘어나는지 확인한다.
  여러 PPO 회차의 평가가 끝나기 전에는 이 관찰을 이유로 정책을 수동 보정하지 않는다.
