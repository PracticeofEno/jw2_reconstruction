# Elf 행동 교정 실험 v107–v108 (2026-09-10)

v108은 실제 사냥 명령을 실행했지만 기존 모델보다 승률이 낮아 채택하지 않았다.
선택된 엘프 신경망은 **v103, 개발 평가 38승 7패 3시간초과 / 48전**으로 유지한다.
이번 실험의 학습·평가는 완료했으며 백그라운드 학습은 실행 중이 아니다.
원시인·데몬·티라노의 선택 모델은 변경하지 않았다.

## 사용자가 관찰한 행동의 원인

공격 중 복귀에는 신경망의 새 명령, 실행기의 자동 후퇴, 저체력 유닛 복귀와
집결 동작이 섞여 있다. 현재 명령·목표·유지 시간·위협·자동 후퇴 상태가 관측에
있으므로 정책이 불필요하게 명령을 바꾸는 행동은 학습 대상이다. 그러나 실행기가
명령을 덮어쓰는 경우에는 해당 규칙도 점검해야 하며 학습만으로 제거된다고 할 수 없다.

- 활성 엘프 교사 진입점: `src/ranker_ai_commander.cpp:1205`의
  `ElfIntegratedFoundationTeacher`, 구현은 `src/ranker_ai_commander_elf_foundation.inc`.
  이 교사에는 HUNT 분기가 없다. 이전 `elf_teacher.inc`에 남은 사냥 분기는 현재 교사로
  호출되지 않으므로 현재 학습 자료에 사냥 예시가 있다고 해석하면 안 된다.
- 교사·v103·v106의 각 48경기를 조사했을 때 사냥 선택은 모두 0회였다.
  각 실제 부대 선택 접두사에서 HUNT가 합법인 관측은 2,814 / 3,400 / 3,599개였다.
  NOOP 접두사는 intent 마스크가 닫히므로 이 수를 모든 잠재 사냥 기회로 해석하지 않는다.
- 새 학습 자료 첫 16경기의 안전한 사냥 후보 58개에서 v106의 HUNT 확률 중앙값은
  약 1.51e-15였다. 단순 PPO 탐색만으로 빈 행동을 배우기 어려운 출발점이다.
- HUNT 액션과 실행기는 이미 있다. `ranker_ai_commander.cpp:1839`의 사냥 표식 설정과
  `:1912`의 `hunt_unit` 실행, `ranker_ai_actions.cpp`의 중립 대상 검사를 확인했다.
- `ranker_ai_commander_game.inc:74`는 중립 소유자 사망을 전투 투자량 보상 집계에서
  제외한다. 승리로 이어지는 간접 효과는 가능하지만 중립 사냥 처치에 대한 직접
  보상이 현재 있다는 뜻은 아니다. 이번 실험은 보상과 게임 규칙을 변경하지 않았다.

## 데이터와 학습 범위

기록 디렉터리: `debug_artifacts/commander/elf_ppo_combat_recovery_20260910`.
체크포인트는 `debug_artifacts/commander/race_strength_20260909/training_run/elf` 아래에 있다.

v106의 티라노전 개선을 보존할 수 있는지 보기 위한 격리 실험으로, 미채택 v106에서
**새 확률적 경기 32전, 행동 33,546개**를 수집했다. 기존 최상 모델은 덮어쓰지 않았다.
구성은 원시인 4전·엘프 4전·티라노 12전·데몬 12전이며 실제 own tribe, 상대,
시작 위치, 모델 버전·해시, 실행 파일, 종료 결과와 native rollout을 검사했다.

개발 맵·시작 위치는 기존 조건을 사용했고 행동 추첨 시드만 새로 부여했다.
이를 새로운 맵에서의 일반화 검증으로 표현하지 않는다. 별도 평가 12전은 기존에
고정한 행동 추첨 시드를 사용했고 해당 trajectory를 학습에 넣지 않았다.

`tools/ai/ranker_commander_behavior_prior.py`에 행동별 보조 학습을 추가했다.

- 경제 관련 출력 0·1·6, 공통 특징과 접두사 임베딩은 고정했다.
  같은 관측·접두사의 보호된 출력은 정확히 같지만 이후 경기 상태까지 고정되지는 않는다.
- v107: 실제 v106 행동·마스크·로그 확률을 그대로 사용한 PPO 3 epoch 이후
  안전한 사냥 시작, 짧은 공격 명령 유지, v103 공격 진입·적 건물 목표를 보조 학습했다.
  사냥 출력은 HOLD 출력에서 낮은 초기 확률로 재초기화했다.
- 교정 표적은 새 학습 관측에 적용한 휴리스틱과 고정 v103의 조건부 출력이다.
  **실제로 교사가 플레이한 사냥 시범 자료가 아니다.** 기록된 PPO 행동, 보상,
  조건부 마스크를 수정하거나 가상의 사냥 목표 마스크를 만들어 넣지 않았다.
- 교정 예시: 사냥 106개, 공격 유지 869개, 공격 진입 771개, 적 건물 선택 305개.
  중복을 제외한 교정 행은 1,998개다.
- v107은 최종 sample joint KL 0.11495로 사전 기준 0.05를 초과해 경기 평가를 하지 않았다.
- v108은 같은 학습 관측만 사용한 보조 학습·KL 보정이다. 오래된 rollout으로
  추가 PPO를 한 것으로 계산하지 않는다. 5 epoch에서 KL 0.03774, clip fraction
  0.04260, 사냥 표적 일치 88/106으로 사전 기준을 통과했다.

## 행동 증거와 남은 문제

`v108_screen_behavior.json`과 `v108_hunt_diagnosis.json`은 학습에 사용하지 않는
읽기 전용 경기 분석 결과다.

- v108은 결정적 12경기 모두에서 HUNT를 선택했다. 부대 사냥 명령은 합계 934회다.
- 12개 리플레이 모두에 자기 소유자의 사냥 표식과 대상 지정 acquire 패킷이 있다.
  표식은 subtype 0x0b / command 0x0d / mask 0x80000000이고, 대상 공격은
  **subtype 0x02** / command 0x0d / nonzero target으로 검사했다.
  이 증거는 실제 명령 전송을 확인한다. 성공한 중립 처치 수나 경험치 증가량을
  증명하는 지표로 대신 쓰지 않는다.
- 공격 상태에서 본진 방향으로 정책 명령을 바꾼 횟수는 같은 12경기에서
  v103 70회 → v108 34회다. 정상적인 방어·후퇴도 포함되므로 불필요한 복귀 횟수나
  문제 해결률이 아니다. 자동 후퇴, 유닛별 복귀, 집결 이동과도 구분해야 한다.
- 새로운 사냥 진입은 82회였고 그중 본진 위협 관측이 있는 진입 32회,
  공격 명령을 끊은 진입 37회, 평균 체력 80% 미만 진입 19회였다. 조건은 중복된다.
  사냥을 권한 학습의 엄격한 시작 조건과 일치한 진입은 3회였다.
- 즉 사냥 출력이 활성화되는 데는 성공했지만 학습한 안전 조건 바깥으로 확장됐다.
  사냥하지 말아야 할 상황과 사냥 종료 이후의 행동을 검증한 시범이 부족하다.
  사냥 빈도 증가나 공격 복귀 감소만으로 더 강해졌다고 판단할 수 없다.
- 분석 파일의 `main_hunt_observed_frames`와 `main_automatic_retreat_decisions`는
  rollout **의사결정 표본 수**다. 실제 시뮬레이션 프레임 수나 연속 지속 시간은 아니다.

후속 작업은 교사에 사냥 시작뿐 아니라 공격·방어 우선, 종료와 복귀까지 포함한
운영을 먼저 검증하는 것이다. 새 훈련용 경기를 모아 사냥 금지·종료 예시와
정상 공격 유지 예시를 함께 학습하고, 실제 승률로 확인한다. 정당한 긴급 후퇴를
없애거나 평가 데이터를 모방 자료로 재사용하지 않는다.

## 검증과 재생

`test_ranker_commander_behavior_prior`의 직접 관련 테스트 5개가 통과했다.
사냥의 native mask·상황 조건, 공격 유지 해제 조건, 출력별 gradient 범위,
사냥 출력 초기화 범위, 경제·critic·실제 행동 기록 보존을 검사했다.
PPO native/Python joint log probability 최대 오차는 7.63e-6,
value 오차는 2.98e-6이었다. 체크포인트 export/reload와 고정 파라미터 동일성을 검증했다.
결정적 평가는 mask 위반·실행 거부 모두 0이며, 별도 확률 평가는 mask 위반 0,
실행 거부 2회로 기록돼 있다. 이를 모두 실행 성공으로 보고하지 않는다.

게임 코드, 배포 실행 파일, 기존 교사와 모델은 이번 실험에서 수정하지 않았다.
원본 게임이나 P2P 동기화에 관한 관련 없는 테스트는 실행하지 않았다.

프로젝트 루트 `play_last_replay.cmd`는 가장 최근 완료 경기 리플레이를 선택한다.
선택된 최상 모델과 최신 실험 모델은 다를 수 있으며, 이번 최신 경기는 미채택
v108의 별도 확률 평가다. `--dry-run`으로 경기와 재생 실행 파일 선택을 확인한다.
자기 편의 새 AI 판단은 재생 중 비활성화하고 기록 명령을 사용하며 상대 내장 AI는 유지한다.

결과 등록 파일은 `training_run/elf/ppo_combat_recovery_20260910.json`,
최종 확인은 실험 디렉터리 `final_verification.json`이다.
다음 PPO 출발점으로는 채택된 v103 actor와 동일하고 critic만 예열한 v104를 권장하며,
미채택 v106·v107·v108을 자동으로 승격하지 않는다.
