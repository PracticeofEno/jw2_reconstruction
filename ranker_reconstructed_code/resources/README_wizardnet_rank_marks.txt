WizardNet rank-mark source
==========================

wizardnet_rank_marks.png is a 5-frame horizontal sprite strip used by the
reconstructed WizardNet online-user list and mark picker.  Each unique frame
is 42x18 pixels; repeated occurrences are excluded.

The five frames are LEAGUE, WIZARD, USER, RANKER, and RANK, selected from the
left-to-right, top-to-bottom occurrences preserved under:
  debug_artifacts/png/original_game/wizardnet_rank_marks_12_individual/

The resource strip is 210x18 pixels and is assembled without resampling.
wizardnet_rank_marks.bmp is its RGB runtime copy embedded in
ranker_rebuild.exe as RCDATA resource 2004.
